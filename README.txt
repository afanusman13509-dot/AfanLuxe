AFANLUXE - AASAN SETUP

Is version mein Supabase nahi hai. Products Netlify ke online storage mein save honge.

SIRF EK DAFA SETUP:
1. ZIP ko Extract karein.
2. Netlify mein apni AfanLuxe website kholein.
3. Project configuration > Environment variables mein jayein.
4. Naya variable add karein:
   Name: AFANLUXE_ADMIN_PASSWORD
   Value: Afan@2026
   (Aap chahein to is value ki jagah apna naya password rakh sakte hain.)
5. Is poore folder ko Netlify par Git deployment ya Netlify CLI se deploy karein. Sirf index.html upload na karein; netlify/functions folder bhi zaroori hai.

AB WEBSITE PAR:
- Admin Login karein.
- Product ki photo aur details daalein.
- Save Product dabayein.
- Product sab logon ke mobile aur computer par nazar aayega. Har product ke liye dobara website deploy nahi karni.

NAYI CHEEZEIN:
- Website khulte hi upar aapki uploaded products ki photos slide hongi.
- Kisi photo ya product par click karne se uski detail khulegi.
- Order on WhatsApp ka button hai: 03121651557
- WhatsApp par product ka naam likha hua message khulega.
- Sirf admin password se product upload/remove ho sakta hai.

ZAROORI:
